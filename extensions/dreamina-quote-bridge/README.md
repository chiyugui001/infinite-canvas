# 即梦实时报价桥（Edge）

该扩展只在本机完成两件事：

1. 在一个非活动的即梦生成页中切换图片或视频模型、分辨率、比例和时长；
2. 视频报价时只输入与画布提示词等长的占位字符，不传递真实提示词；
3. 把网页已经显示的积分数字回传给 `127.0.0.1:17371` 的 Canvas Agent。

扩展不会读取或复制 Cookie，不会传递真实提示词和参考素材，也没有点击生成按钮的代码。

已由官方页面核验的规则会按参数保存在本机；显示可复用 24 小时，付费提交超过 30 分钟必须重新核验。图片支持 5.0 Lite、5.0 Pro，文本视频支持已列出的 Seedance 模型。带参考素材的视频在无法安全复现官方报价时会阻止提交，不使用猜测价格。
